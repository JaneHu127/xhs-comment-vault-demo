# 小红书评论研究库 Web Demo

这是用于简历与作品集展示的静态交互 Demo。页面只使用模拟数据，不会读取本地插件数据库，也不包含任何 API Key。

## 本地预览

直接打开 `index.html` 即可。也可以使用任意静态文件服务器预览。

## 部署

整个 `web-demo` 目录可以直接部署到 GitHub Pages、Cloudflare Pages、Netlify 或 Vercel，无需构建命令。

- 发布目录：`web-demo`
- 构建命令：留空
- 输出目录：`.`

## 演示功能

- 按标签筛选收藏
- 搜索评论、作者和笔记
- 富文本编辑与标签修改
- 取消收藏及撤销
- 标签级 AI 摘要
- 基于当前标签的模拟继续追问
- 桌面端和移动端响应式布局
